# Quarto Semestre - Engenharia de Software

Repositório com os materiais, exercícios e projetos desenvolvidos ao longo do quarto semestre do curso de Engenharia de Software.

## 📚 Disciplinas

### Banco de Dados II
Estudos, exercícios e anotações da disciplina de Banco de Dados II, com foco em banco de dados **MongoDB (Atlas)**.

📁 [`ESTUDOS DE BANCO DE DADOS II`](./ESTUDOS%20DE%20BANCO%20DE%20DADOS%20II)
- Coleções JSON de exemplo (catálogo, estoque, insumos, planejamento de impressões)
- [Estudos para a Prova 1](./ESTUDOS%20DE%20BANCO%20DE%20DADOS%20II/Estudos%20Prova%201): Atlas/Compass/Cluster, dicionário de dados, modelagem, quiz e perguntas

### Introdução às Tecnologias para Web
Materiais e exercícios práticos sobre tecnologias web, utilizando **HTML, CSS, JavaScript e Bootstrap**.

📁 [`INTRODUÇÃO ÀS TECNOLOGIAS PARA WEB`](./INTRODUÇÃO%20ÀS%20TECNOLOGIAS%20PARA%20WEB)
- `Aula1` a `Aula4`: exercícios feitos em aula (estrutura HTML, CSS, formulários, Bootstrap)
- `Atv. 01` a `Atv. 03`: atividades entregues (Guia de Viagens, Currículo, Catálogo de Cursos)
- `Estudos/P1`: exemplos de HTML e CSS para a P1
- `Estudos/P2`: requisições HTTP com JavaScript (GET, POST, PUT, DELETE) para a P2

### Paradigma e Programação Orientada a Objetos
Exercícios práticos de POO em **Java**, incluindo implementação de classes, encapsulamento, herança e outros conceitos do paradigma orientado a objetos.

📁 [`PARADIGMA E PROGRAMAÇÃO ORIENTADA À OBJETOS`](./PARADIGMA%20E%20PROGRAMAÇÃO%20ORIENTADA%20À%20OBJETOS)
- `Prática/Aula1` a `Aula3`: classes Data, Horario e o jogo da Forca
- `Prática/Prova1`: exercícios da Prova 1
- [`Prática/JogoDaVelha`](./PARADIGMA%20E%20PROGRAMAÇÃO%20ORIENTADA%20À%20OBJETOS/Prática/JogoDaVelha): Jogo da Velha contra o computador, feito em dupla com [Gabriel Coutinho](https://github.com/gcoutiinho)
- `Estudos`: versões revisadas das classes (Data com `Comparable` e `Cloneable`, Horario, Aluno, Forca) e exercícios dos simulados

## 🛠️ Tecnologias

- **Java** — Paradigma e Programação Orientada a Objetos
- **MongoDB Atlas** — Banco de Dados II
- **HTML / CSS / JavaScript** — Introdução às Tecnologias para Web

## 📖 Sobre

Este repositório é organizado por disciplina, cada uma em sua própria pasta, contendo os exercícios e materiais de estudo produzidos ao longo do semestre.
