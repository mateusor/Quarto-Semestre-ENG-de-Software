# Currículo Pessoal - HTML & CSS

Atividade da disciplina, com o objetivo de construir uma página de currículo pessoal usando HTML (estrutura) e CSS externo (estilo), aplicando os elementos vistos em sala (seletores por tag, id e class, box model, listas, tabelas, etc.).

## Arquivos

- `index.html` — estrutura da página do currículo.
- `estilo.css` — arquivo de estilo externo (todo o CSS do projeto).

## Como visualizar

Basta abrir o arquivo `index.html` em qualquer navegador. Como o CSS está em um arquivo externo (`estilo.css`) na mesma pasta, o link já é carregado automaticamente.

## Conteúdo da página

- Cabeçalho com nome, foto/avatar e título profissional.
- Dados de contato (e-mail, telefone, cidade, GitHub, LinkedIn).
- Resumo profissional.
- Formação acadêmica (tabela).
- Experiência profissional (lista com sub-itens de responsabilidades).
- Competências técnicas (tabela habilidade × nível).
- Idiomas.
- Rodapé com direitos autorais.

## Requisitos atendidos

- [x] Títulos e textos (`h1`, `h2`, `h3`, `p`)
- [x] Lista não ordenada (`ul`, `li`) — contato, experiência e idiomas
- [x] Imagem de perfil (`img` com `alt`)
- [x] Tabelas — formação acadêmica e competências técnicas
- [x] CSS externo (`estilo.css`), sem estilos inline
- [x] Sem uso de frameworks CSS ou bibliotecas JS

## Tecnologias usadas

- HTML5
- CSS3 (seletores por tag, id e class)
